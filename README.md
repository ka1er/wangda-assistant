# 网大助手

用于中移网大的篡改猴脚本。输入专区名称、核对课程并加入任务队列，可依次学习多个专区的课程。根据每张课程卡片预选待学内容，执行时等待平台确认课节完成，再切换课节和课程。

当前版本：**0.1.0-beta.13**，供小范围试用。自动化测试使用模拟页面；真实账号的全程学习和学时统计尚未完成核验。

## 安装与升级

首次安装：

1. 在 Chrome 或 Edge 中安装 Tampermonkey（篡改猴）。
2. 打开[固定测试版安装地址](https://raw.githubusercontent.com/ka1er/wangda-assistant/refs/heads/beta-channel/dist/wangda-assistant.user.js)，在篡改猴页面确认安装。
3. 如果只显示脚本文本，可以在 Tampermonkey 管理面板添加新脚本，用该地址的全部内容替换编辑器原有内容，保存。
4. 允许扩展访问 `wangda.chinamobile.com`。若浏览器提示需要“允许用户脚本”或开发者模式，按提示开启。
5. 打开中移网大，登录后刷新。右下角出现“网大助手”，点击展开。

升级时，先暂停正在执行的任务，然后在篡改猴中编辑**原来的网大助手脚本**，用新版全部内容替换并保存，再刷新网大。保留原脚本才能沿用它的本地任务数据，请避免同时启用两个副本。

从 beta.8 或更早版本迁移时，需要用上面的固定地址手动更新原脚本一次。beta.9 起包含固定的更新与下载地址；在篡改猴中启用脚本更新检查后，后续会按扩展设置检查新版，也可手动执行检查更新。原来的 `beta/版本号` 地址只保留对应版本，不会跟随测试通道。此地址接收经过检查后发布的测试版，仍可能存在尚未实测的问题。

旧版单专区任务会恢复成队列中的一个任务，保留课程选择、完成记录和学习时段，刷新后仍为暂停。如果旧任务设置了“仅必修”，会保留原来的必修课程及课节范围并在任务中注明；需要包含选修时，可将该任务移出后重新添加专区。新添加的任务均检查所选课程的全部课节，包含选修。

卡片状态预选适用于新添加的任务；更新已有任务清单时，会保留原来的勾选。指定课程任务的新课默认不选。

## 添加多个专区

1. 点击“添加专区”，输入名称并搜索，确认搜索结果中的目标专区；也可以自行打开专题后读取当前专题。
2. 核对课程清单。每门课程卡片明确显示已完成的默认不选；未开始、学习中的默认选中，必修和选修都包含；无法识别的状态标为待确认，需自行核对后勾选。
3. 调整勾选后加入队列。可用“全部未完成、仅必修、清空选择”批量设置；待确认和已完成课程不会被批量选中，需要时可逐门手动勾选。“仅必修”选择必修待学课程，所选课程仍检查全部课节。
4. 重复上述步骤添加其他专区。同一专区不会重复加入或覆盖原任务。
5. 在队列中打开任务详情，可以调整课程选择或更新课程清单。已有勾选和完成记录会保留；“专区全部待学”下新增待学课程按卡片状态预选，“指定课程”下新增课程只展示、不自动选中。

### 只学专区中的某几门

读取专区后，把“学习范围”设为 **指定课程**。切换时会清空预选，请输入课程名称或关键词筛选，再逐门勾选需要的课程并加入队列。任务详情也可切换范围；切回“专区全部待学”会按待学状态重新预选，切换前请留意提示。

筛选只控制显示，**不会取消隐藏课程的勾选**。清单会显示已选总数；“全部未完成”“仅必修”“清空选择”“勾选已完成”作用于整份清单。指定任务更新清单后，新出现的课程需要你手动勾选才会执行。

### 复查已完成课程有没有新增内容

卡片显示已完成仍可以手动勾选。新添加任务会进入所选课程，核对真实课节状态；也可以用“勾选已完成”批量选中后核对范围。

已有任务需要重新检查时，在详情中勾选目标课程，再点击 **复查所选已完成课程**，然后开始。助手保留原完成记录，将这些课程标为待复查；发现未完成课节则正常学习，全部课节已完成就结束该门复查。复查安排会保存，刷新后仍在；遇到人工环节或跳过时继续显示待处理，不计本轮完成。

遇到“重新学习”提示或平台归档中间页，助手会暂停并保留任务。请先在网大核对提示后人工处理，进入课程或专区；准备添加的任务重新读取专区，已加入的队列手动继续。已确认的归档页面按钮会调用平台恢复接口并打开新窗口，因此本版不会自动点击；请关闭旧的学习窗口后在需要的标签页继续。

任务默认按添加顺序设置执行优先级。拖动专区卡片右上角的 **↕** 手柄，或点击“上移”“下移”，可以调整优先级并自动保存；卡片上标注的数字越小越先执行。

当前执行的专区始终置顶并显示浅蓝背景，其余未完成专区按优先级展示。所选课程全部确认完成的专区会移到底部并显示浅灰背景；有跳过、待处理或待复查课程的专区仍属于未完成。已完成专区不参与排序，安排复查或加入新的待学课程后会恢复到未完成区域。展示分组保留原有执行优先级。

**学习中也可以排序，无需暂停。** 当前课程继续，切到下一门时按保存的执行优先级选择待学课程。例如正在学习 A，把 B 拖到 A 卡片的上半部以提高优先级，当前这门 A 课程完成后先学 B，之后再回来学 A 的剩余课程。A 在当前课程完成前仍置顶展示，卡片上的优先级数字会随调整更新。重试或等待学习时段时也可调整，正在搜索、读取专区或恢复任务时暂不能调整。

任务内仍按课程列表顺序执行。排序保留所有课程勾选、完成及待处理记录，刷新后仍沿用已保存顺序。课程清单来自专题页面；助手无需解析领导通知，也不会根据文字推断必修或选修范围。

## 开始、暂停和继续

核对全局北京时间窗口，默认 `09:00—24:00`。`24:00` 表示当天结束。点击开始后，助手会在同一标签页进入队列中的待学课程，并在完成后进入下一门、下一个专区。

展开时，顶部显示运行状态和队列总完成数；当前课程、课节及播放时间集中在蓝色专区卡片里。打开课程详情后，由当前课程行展示这些信息；筛选隐藏当前课程时，卡片仍保留摘要。卡片只显示完成门数和非零待处理项，范围与勾选在详情中查看。长名称截短显示，悬停可看全名。

收起后显示当前课程、播放时间和队列总完成数。标题栏按钮随状态显示“开始”“暂停”或“继续”；全部完成后显示“已完成”。异常原因仍会显示。进度分母是勾选的课程数，未勾选的课程不计入。

能读取当前页原生音视频的有效时间时，当前课程和收起面板会显示课节播放时间，例如 `13:48 / 51:41`，课程行另有蓝色播放进度条。这里表示当前课节的播放位置；专区完成门数仍以平台课节状态确认。图文、跨域播放器或未知时长只显示执行状态，暂停、切换或重试时会清除旧播放时间。

视频和音频按平台正常方式播放，图文、文档等等待平台显示“已完成”。播放器结束本身不代表平台确认完成。助手先等待站点自行切换，仍停留时再执行下一步。

播放中途普通暂停时，助手先等待约 2 秒，再在当前课节自动恢复，恢复成功不弹通知，无需开启自动重试。同一课节短时间内最多尝试三次，连续恢复失败或请求超时才暂停并提醒。恢复会保留该课节内手动调整的声音设置。需要主动停下来时，请使用**助手的暂停按钮**；只暂停播放器会触发自动恢复。

“自动模式”中提供独立的**自动静音课程**开关，默认开启，选择会保存。暂停任务后可修改，无需开启自动重试。开启时，开始或继续队列、新课节或更换播放器都会应用静音；同一课节内手动开声后会保持，原音量值保留。关闭后按播放器原声音设置播放；已经静音的播放器可手动开声。

点击暂停或到达时段终点，会停止当前任务对应学习页的媒体并退出该页。默认刷新或重新打开后暂停，需要手动继续。更新课程清单或修改勾选不会清空其他课程的完成记录。

### 设置一次后自动执行

展开面板，在“自动模式”中开启“自动重试、暂存异常课程并续学”，再点击开始。开关只需设置一次，会保存在本地；升级后默认关闭，原来的任务和勾选保留。

- 课程加载、切换或播放初始化失败：分别等待 5、10、20 秒重试，每门课程最多三次。再次失败后暂存该课程，继续后续任务。
- 考试、测验、作业、H5、外部链接等人工环节：将整门课程放入待处理清单，继续下一门。队列结束后集中提示；任务详情中保留原因和“重试”按钮。
- 当前不在允许时段：等待到开始时间再执行；运行到截止时间会停止并退出学习页，下次允许时段自动继续。
- 浏览器明确离线：显示“等待网络”，不消耗重试次数；网络恢复后重新进入课程。

需要刷新或重新打开页面后继续，可另行开启“刷新或重新打开后恢复已开始的队列”。只有已经点击开始的自动任务会恢复，仍会重新取得同源执行锁。**你主动点击助手的暂停后不会自动继续。** 登录失效、平台学习限制或被其他学习窗口接管时，仍会停止提醒，需要处理后手动继续。

待处理与跳过都不计为完成。请保持浏览器和网大页面打开；电脑休眠、页面关闭时助手无法执行。

同一浏览器中只允许一个标签页执行，请在执行中的标签页操作暂停。不同浏览器或配置文件之间不共享运行锁。关闭浏览器或电脑休眠后不会继续执行；断网后无法保证进度保存。

时段控制依赖浏览器正常运行，后台节流或休眠可能延迟暂停。首次试用请保持标签页在前台，先用少量课程核对平台进度和学时记录。

## 遇到需要处理的课程

未开启自动模式时，播放被阻止、加载超时或遇到考试、测验、作业、H5、外部链接等环节会暂停并说明当前课程及原因。开启后按上面的重试与暂存规则继续执行。

- **重试**：处理问题后重新检查该课程。
- **跳过并继续**：暂时保留为未完成，先执行其他课程。
- **暂停**：停止执行；需要时手动继续。

跳过不等于完成。队列执行到末尾，如果仍有跳过课程，会提示还有未完成内容；可以在任务详情中重试。需要人工播放或答题时，部分暂停会保留当前页面；需要离开学习页时，展开面板点击“停止学习并退出”。

助手不作答、不修改进度，也不代替平台确认学时。当前适配“专题 → 课程 → 课节”结构，自定义专题、直接放在专题中的非课程资源和跨域播放器可能需要人工处理。

## 排查问题

打开页面诊断，可查看页面类型、课程/课节数量、资源类型和状态。数量不对时，先等待页面加载完成再读取。反馈时可以提供面板提示和诊断信息，请去掉业务课程内容及个人信息。

搜索有重名或相近名称时，请核对目标专区。不要同时运行多个自动切课脚本，以免互相干扰。

点选专区后，助手会核对专区标识、标题和课程清单。自定义布局没有标准横幅时，会读取站点设置的浏览器标签标题。若等待后仍无法读取，会明确提示标题缺失、标题不一致或加载超时。可以先点“暂停”，核对页面后再点“读取当前专区”；页面诊断中的 `subjectTitleSource` 表示标题来源（`banner` 为横幅，`document` 为标签标题，`none` 为未识别）。

## 本地构建

需要定位“打开另一门课程后暂停”的问题时，可单独安装[播放暂停诊断脚本](docs/playback-diagnostics.md)，按步骤导出两个标签页的事件时间线。

需要 Node.js 24 或更新版本。

```powershell
npm install
npm run check
```

`npm run check` 构建单文件脚本、检查语法并运行测试。`src/` 是源码，`tests/` 使用合成页面，不包含真实学习记录。

维护现状、已知问题和后续计划见 [HANDOFF.md](HANDOFF.md)。
